# HW08: AI 智能文档问答助手

## 1. 项目简介
本项目是《人工智能科技前沿》课程的期末综合项目。应用基于 RAG（检索增强生成）技术架构，允许用户上传任意 PDF 格式的学术论文或长篇报告。系统通过语义向量检索精准定位知识片段，并结合大模型进行阅读理解与多模态溯源总结，解决长文档阅读低效、传统搜索无法理解上下文的痛点。

## 2. 目录结构
- `app.py`: Streamlit 前端 UI 交互界面与入口。
- `src/`: 核心业务逻辑解耦包。
  - `document_utils.py`: 负责本地文档的动态加载与分块切片。
  - `rag_engine.py`: 负责调用云端 Embedding 模型、构建本地 FAISS 向量库并封装大模型调用链。
- `requirements.txt`: 项目标准依赖清单。
- `.env.example`: 环境参数配置模板。
